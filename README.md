# Model-Selection
Model Selection &amp; Training

This is a Machine Learning life cycle after data collection .

1. Feature engineering is the process of selecting, transforming, and creating input variables (features) from raw data to improve the accuracy and efficiency of machine learning models.
2. Model selection is the process of choosing the best-fit algorithm and architecture for a specific problem while balancing predictive accuracy, generalization, and resource limits
3. Model evaluation is the process of measuring how well a machine learning model performs and generalizes to unseen data. It ensures the model has learned true patterns rather than just memorizing the training data (overfitting)

The collected data sets are from Kagle in CSV format:
-Telco Customer Churn
-Credit card set
-customer segmentation
